# Bin Matrix Mobile (React Native CLI)

This is a React Native CLI mobile application. Prioritize mobile-first patterns, performance, and cross-platform compatibility.

## Tech Stack
- **Framework**: React Native 0.88.1 (React Native CLI)
- **Language**: TypeScript
- **Bundler**: Metro
- **Vector Graphics**: `react-native-svg`
- **Native Directories**: `android/` and `ios/`

## Commands

```bash
# Start the Metro bundler
npm start
# or: npx react-native start

# Run on Android emulator / connected device
npm run android
# or: npx react-native run-android

# Run on iOS simulator (macOS only)
npm run ios
# or: npx react-native run-ios

# Type checking
npx tsc --noEmit

# Linting
npm run lint
```
